# 应用落点

双击 `AppLanding.exe` 即可在 Windows 10/11 上使用。桌面程序采用原生 WPF，无需另行安装桌面壳或启动网页服务。

1. 将一个 MSI、EXE、ZIP 或便携版文件夹拖到窗口中央。也可使用选择按钮。
2. 在「目标位置」输入本机磁盘路径，或点击「浏览」。界面会预览最终目录，例如 `D:\Apps\示例工具`。
3. 核对应用文件夹名，点击「开始安装」或「开始收纳」。找到目标文件夹后，可直接打开。

| 文件类型 | 行为 |
| --- | --- |
| MSI | 读取安装包目录表，优先采用识别到的默认目录名，并将完整路径交给原安装向导。若属性未识别，可输入厂商文档提供的属性名。 |
| Inno Setup / NSIS EXE | 手动确认安装器类型后传入相应路径参数。文件夹名优先使用 EXE 元数据中的产品名称，可手动修改。 |
| ZIP、便携版文件夹、单文件便携版 EXE | 在目标位置创建同名目录，解压或复制文件。保留源文件，不执行便携版程序，不覆盖同名目标。 |

原安装包可以忽略目录参数，也可能将共享组件写入系统盘。安装时请在原向导中核对实际目录。没有可靠路径参数的安装器、Microsoft Store、MSIX 和其他压缩格式暂未接入。

`demo/index.html` 可离线打开，播放模拟拖放与收纳的动画。它参考 Stageshow 的 Upload 示例，演示不会访问文件系统。检查范围见 `demo/REHEARSAL.md`。

`App.cs`、`Engine.cs` 和 `Main.xaml` 是桌面应用源码。使用当前系统的 64 位 .NET Framework C# 编译器与 WPF 程序集构建，构建参数见 `build.ps1`。程序未经代码签名。

已在本机验证 XAML 加载、EXE 处理方式选择、完整路径预览、便携文件复制、ZIP 解压、同名目录保护、ZIP 路径检查与下载来源标记保留。MSI、Inno Setup、NSIS 的真实安装尚未做端到端验证。
